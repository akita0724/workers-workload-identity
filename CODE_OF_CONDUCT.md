# Code of Conduct

[English](CODE_OF_CONDUCT.md)

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies to everyone who takes part in the project's issues, pull requests, discussions, and other project spaces.

## Expected behavior

Be respectful and constructive. Assume good intent, give specific technical feedback, and accept that people work in different languages and time zones. Japanese and English are both welcome.

## Reporting

Report unacceptable behavior privately to the maintainer, [@akita0724](https://github.com/akita0724), through the contact listed on that GitHub profile. Do not report conduct issues in a public issue. Security vulnerabilities follow [SECURITY.md](SECURITY.md) instead.

The maintainer will review every report, keep the reporter's identity confidential, and respond according to the enforcement guidelines of the Contributor Covenant.
