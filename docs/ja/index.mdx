`workers-workload-identity` は、Cloudflare Workers 上のサービスへ、ワークロードアサーションと呼ぶ短命の署名付き JWT を発行します。caller は Service Binding に固定した `ctx.props` で識別し、公開の token endpoint は設けません。relying party は公開 JWKS でアサーションを検証します。

:::warning
本プロジェクトはアルファ版（`v0.1.0-alpha.0`）です。Worker 間の発行と検証はローカルと Cloudflare のステージング環境で確認済みですが、外部プロバイダーとの token exchange は未検証です。評価環境にだけデプロイしてください。[リリース状況](./reference/release-status.md)を参照してください。
:::

## 最初に読むページ

1. [ワークロード ID フェデレーションとは](./oidc.mdx)では、本プロジェクトが提供する機能、OpenID Provider との違い、信頼境界を説明します。
2. [クイックスタート](./getting-started.mdx)では、ローカルの E2E テストを実行し、隔離したステージング用アカウントへデプロイします。
3. [セキュリティモデル](./reference/security.md)では、デプロイ前に対処すべき脅威を説明します。
