`workers-workload-identity` issues short-lived, signed JWTs, called workload assertions, to services running on Cloudflare Workers. It identifies each caller from the fixed `ctx.props` of its Service Binding and exposes no public token endpoint. Relying parties verify assertions with the published JWKS.

:::warning
This project is in alpha (`v0.1.0-alpha.0`). Issuance and verification between Workers pass locally and in a Cloudflare staging environment, but token exchange with external providers has not been verified. Deploy it only to evaluation environments. See [release status](./reference/release-status.md).
:::
