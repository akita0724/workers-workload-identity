# Support

[English](SUPPORT.md) | [日本語](SUPPORT.ja.md)

`workers-workload-identity` is in alpha and does not currently provide production support or a response-time SLA.

Use a public GitHub issue for reproducible bugs, documentation corrections, and feature proposals after removing all sensitive values. Include the commit, environment, minimal reproduction, expected behavior, actual behavior, and the checks you ran.

Provider names in the documentation are evaluation targets, not support claims. Check [Provider support](docs/reference/provider-support.mdx) before planning an integration.

Do not use a public issue for a vulnerability. Follow [SECURITY.md](SECURITY.md) instead.
